# Classical Machine Learning Projects

This repository showcases two classical machine learning projects implemented using **scikit-learn**, focusing on both classification and regression problems.

## Project 1: Iris Classification
**Goal:** Build and analyze linear classifiers to identify Iris flower species.  
**Models:** Perceptron and Adaline classifiers (implemented using scikit-learn).  

**Highlights:**
- Achieved **100% accuracy** on linearly separable subsets.
- Compared **Perceptron vs Adaline** learning behavior and convergence.
- Analyzed generalization on non-linear subsets.

**Tech Stack:** Python, NumPy, Pandas, Matplotlib, scikit-learn

---

## Project 2: Bike Rental Demand Prediction
**Goal:** Predict daily bike rental counts based on weather and time features.  
**Models:** Linear Regression, Ridge Regression, Lasso Regression.  

**Highlights:**
- Preprocessed dataset with feature encoding and normalization.
- Evaluated models using **RMSE** and **R²** metrics.
- Identified key drivers like temperature, humidity, and seasonality.

**Tech Stack:** Python, scikit-learn, Pandas, NumPy, Matplotlib, Seaborn

---

## Key Learnings
- Understanding of linear and regularized regression models.
- Evaluation of model performance using quantitative metrics.
- Visualizing relationships between features and model predictions.
